The two runnable files, found in src/Assg1, are EncryptVIC.java and DecryptVIC.java,
which respectively encrypt and decrypt data using the simplified VIC cipher.
Each file takes an input text file as a command-line argument, with the .enc files
in the src directory being designed for encryption and the .dec files being designed
for decrpytion. Credit goes to classmate Aaron Lam for writing these test files.

File-specific details can be found in documentation comments at the top of each file.
